# 軽量表示の検証

対象実装: 3a4acc2edd578e737a2bd30b946eceda9a8b6952（2026-10-23）。

## 適用範囲と仕様

- 初期化時に reduced-motion / Save-Data / メモリ1〜4GB / 論理CPU1〜4個のいずれかを検出すると軽量表示。取得できない値だけでは軽量化しない。
- localStorage の jinrou-effects=light/full が自動判定に優先。切替は即時反映し、再読み込み後も維持。同じ端末・ブラウザー・オリジン内の設定。
- html.performance-light により body 背景、疑似要素、夜/夕/朝の背景、順位と行動演出の装飾、ヒーローとボタンの光を抑制。全要素の filter/backdrop-filter を解除し、一部の出現・切替を短縮、死亡演出の雲/月/村の動きを停止。
- 全アニメーションを消すモードではない。全画面の演出要素と待ち時間、音声、通信、サーバー進行は残る。OSの reduced-motion CSS は通常表示を選んでも有効。
- 設定変更イベントの購読はなく、OS・Save-Dataの変更は再読み込み後に自動判定される（手動保存があれば保存値優先）。

## 自動確認

```sh
npm ci
npm test
npm run build
npm install --prefix tests/browser --ignore-scripts --no-audit --no-fund
npx --prefix tests/browser playwright install --with-deps chromium webkit
npm test --prefix tests/browser
```

Playwright依存は既存Vitestと分離し、直接依存を1.56.1に固定。子パッケージはlock未作成のため推移依存の完全固定ではない。初回インストールにはネットワークが必要。

Chromium 360×640 と WebKit 390×844 のモバイルエミュレーションで以下を検査する。

- 自動判定の各条件・4の境界・情報不明・保存値の優先・不正な保存値。
- 通常/軽量それぞれでホーム→作成画面の移動、名前入力、入力を保った切替、双方向の保存と再読み込み。
- ホーム・作成・役職一覧の横スクロール、ヘッダーボタンの画面外・相互重なり。役職一覧スクリーンショットを目視確認用に保存。
- body直下のCSS検査用要素で、ぼかし解除・装飾停止・通常表示への復帰。実際のルーム進行を再現したテストではない。
- 切替が5秒以内に完了する大まかな停止検出と、pageerror検出。計測JSONは自動操作の待ちを含み、INPや実機のタップ遅延ではない。

専用CIはPRとmain push、手動実行で動く。失敗時のスクリーンショット/トレースとHTMLレポートを mobile-effects-results に保存。Firebase変数を空にして起動し、ブラウザーの外部HTTP要求も拒否する。本番ルームを作らない。フォントも遮断するため、実フォントによるレイアウトは実機項目に残す。

## 通信・待ち時間の比較手順

1. 同じcommit・端末・ブラウザー・ネットワーク条件で比較。省電力、CPU/回線制限、キャッシュ有無、BGM ON/OFF、人数と役職を記録。両モードを交互に各5試合以上。3人と20人は別集計。
2. 初期ロードはキャッシュ削除とウォームを分け、Networkの転送バイト・要求数・ロード時間を記録。BGMファイルは大きいため別計上。Save-Dataによる音源削減は実装されていない。
3. テスト用Firebaseで投票確定・夜行動完了・フェーズ移行の操作時刻、Callable終了時刻、画面反映時刻を記録。各操作20回以上で中央値/p95/最大値、RTDB/Callable要求数・転送バイトを集計。画面更新を待つ間の重複タップも記録。
4. DevTools HAR/Performance記録を保存し、個人情報・トークン・役職情報を除いて共有。ネットワーク時間と描画時間を分ける。CIの外部通信禁止テストは本項目の代替にならない。
5. 通常と軽量でゲーム状態・通知を欠落させず、軽量への切替自体がFirebase要求を増やさないことを確認。通信量が同じでも失敗ではない。差分とサンプル数を記録し、測定するまで速度改善を断定しない。
